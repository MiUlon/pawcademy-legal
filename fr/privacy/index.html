Politique de confidentialité

En bref

Pawcademy fonctionne sans compte. Ce que vous saisissez sur vos chiens reste sur cet appareil. Nous n'avons aucun serveur qui reçoit vos données, et l'application n'a ni publicité ni analyses. Les seules exceptions sont les achats et, si vous les activez, les rapports de plantage, décrits ci-dessous.

Ce qui est enregistré sur cet appareil

Les noms, dates de naissance et tailles de tes chiens, les problèmes et objectifs choisis, les heures de rappel, les séances d’entraînement, les progrès, les habitudes cochées, les bilans des programmes et leurs notes, ainsi que les réglages de l’app.

Rappels

Les rappels d’entraînement sont des notifications locales créées par l’app sur cet appareil. Rien n’est envoyé à un serveur pour les délivrer.

Sauvegardes

La sauvegarde de ton téléphone (iCloud ou Google) peut inclure les données de l’app. Ces sauvegardes sont gérées par Apple ou Google selon leurs conditions.

Achats

Les achats sont traités par l'App Store ou Google Play ; Pawcademy ne voit jamais vos données de paiement. Pour vérifier ce que vous avez acheté, l'application utilise RevenueCat, qui reçoit un identifiant anonyme aléatoire, vos données d'achat et des données simples sur l'appareil, comme la version de l'application. Les données sur vos chiens et l'entraînement ne sont jamais envoyées.

Rapports de plantage (facultatif)

Seulement si vous activez Réglages > Envoyer les rapports de plantage : quand l'application plante ou affiche un écran d'erreur, elle envoie un rapport à Sentry, notre service de rapports de plantage. Un rapport contient l'erreur, l'endroit du code de l'application où elle s'est produite, la version de l'application et des données de base sur l'appareil, comme le modèle de téléphone et la version du système. Il ne contient aucun nom, compte ni identifiant publicitaire, et jamais vos chiens ni vos données d'entraînement. Désactiver l'option, ou Supprimer toutes les données, les arrête.

Supprimer tes données

Réglages > Supprimer toutes les données efface en une fois tous les chiens, enregistrements et réglages de cet appareil. Désinstaller l’app les efface aussi. Les données d’achat chez RevenueCat et les éventuels rapports de plantage chez Sentry ne sont pas stockés sur cet appareil ; pour les faire supprimer, écris à mindegi15@gmail.com.
